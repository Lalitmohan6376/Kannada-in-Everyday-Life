# 🌐 Kannada Saathi - Frontend

This is the client-side single page application for **Kannada Saathi (ಕನ್ನಡ ಸಾಥಿ)** built with React 19, Vite, and Tailwind CSS v4.

For full project documentation, setup, and backend instructions, please refer to the main [Root README](../README.md).

## 🚀 Quick Run

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```

## ⚙️ Environment Variables

Copy `.env.example` to `.env`:
```env
VITE_API_BASE_URL=http://127.0.0.1:5000
```
